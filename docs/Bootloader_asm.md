# my
Bootloader 是上电后运行的第一段代码，它的核心任务是在无操作系统支撑的环境下，亲手完成 CPU 从初始状态到可运行内核状态的过渡。因此，前置的体系结构知识高度集中在 CPU 模式切换、内存寻址的建立、以及裸机环境下的硬件交互。

### x86 平台：模式切换是主线

如果面向 PC（x86）开发，Bootloader 的体系结构知识几乎全部围绕“如何从 16 位实模式一步步爬到 64 位长模式”展开。

1. 实模式（Real Mode）的约束
CPU 上电即处于实模式：16 位寄存器、20 位地址空间（上限 1MB）、`segment:offset` 定址方式。BIOS 会将 Bootloader 加载到固定的物理地址 `0x7C00` 处执行。你需要理解这个地址的由来，以及实模式下可安全使用的内存范围（通常避开视频内存和 BIOS 数据区）。

2. 模式切换的完整链路
x86 没有从实模式直达长模式的路径，必须经过保护模式中转。Bootloader 需要按顺序完成：
- 开启 A20 地址线：解除 1MB 寻址限制，通常通过操作端口 `0x92` 实现。
- 加载 GDT：建立全局描述符表，定义代码段和数据段的基址、限长与权限。
- 置位 CR0.PE：开启保护模式，随后通过远跳转刷新流水线。
- 进入长模式：在保护模式下配置 PAE（CR4.PAE）、设置临时页表、置位 EFER.LME 和 CR0.PG，最终完成到 64 位的切换。

3. 分页机制的建立
长模式强制要求开启分页，且使用 4 级页表（PML4）。Bootloader 必须在跳入内核前构建好临时页表，将内核将要运行的虚拟地址映射到物理内存。这是理解后续内核内存管理的前置实操。

4. 裸机磁盘 I/O 与中断调用
没有操作系统意味着没有 `read()`。Bootloader 需通过 BIOS 中断 `INT 13h` 从磁盘读取内核镜像到内存。这要求理解 BIOS 中断的调用约定（参数寄存器、返回状态），以及如何用汇编实现扇区读取循环。同时，`INT 10h` 常用于早期调试输出。

5. 栈的建立与调用约定
在跳入 C 语言编写的内核或 Bootloader 后续阶段之前，必须手动设置栈指针。实模式下需要理解 `SS:SP` 的配合，以及栈向低地址生长的规则，确保不会覆盖已加载的代码或数据。

### ARM 平台：SoC 初始化与异常向量

ARM 平台的 Bootloader 知识重心从“模式切换”偏移到“SoC 特定硬件的裸机初始化”。

1. 异常向量表与处理器模式
ARM 处理器上电后从固定地址（如 `0x0` 或 `0xFFFF0000`）取指执行。Bootloader 需要在入口处放置异常向量表，并尽快切换到 Supervisor 模式，为后续初始化准备合适的处理器状态。

2. DRAM 控制器初始化
这是 ARM Bootloader 最关键的体系结构相关步骤之一。芯片上电时 DRAM 尚未就绪，Bootloader 必须根据 SoC 手册配置 DRAM 控制器，才能将自身剩余部分或内核从 Flash 搬运到内存中运行。

3. MMU 与缓存控制
在启用缓存和 MMU 之前，需要理解 ARM 的协处理器（CP15）操作，包括无效化缓存、设置页表基址寄存器。Bootloader 可以选择在早期不开启 MMU（直接使用物理地址），也可以建立简单的恒等映射后开启，这取决于后续阶段的复杂度。

4. SoC 特定外设的裸机驱动
与 x86 依赖 BIOS 不同，ARM Bootloader 通常需要自行点亮串口（用于调试输出）、配置定时器、甚至初始化 GPIO。这些操作直接读写 SoC 的 MMIO 寄存器，要求能够阅读芯片数据手册并正确操作寄存器位。

### 跨平台共通要点

无论 x86 还是 ARM，以下知识都是必需的：

| 知识领域 | 在 Bootloader 中的具体作用 |
| :--- | :--- |
| 链接脚本与内存布局 | 控制代码/数据在镜像中的位置，确保入口点位于硬件规定的地址（如 x86 的 `0x7C00` 或 ARM 的 `0x0`） |
| ELF 文件格式 | 从编译产物中提取代码段和数据段，按物理内存布局拼装成可启动镜像 |
| 字节序与数据对齐 | 读取磁盘扇区或操作硬件寄存器时，保证多字节数据的正确解释 |
| 硬件手册阅读能力 | Bootloader 高度依赖具体 SoC/芯片组，寄存器定义、时序要求均来自数据手册，没有通用标准可循 |

学习路径建议：若想动手实践 x86 方向，普林斯顿的 COS 318 课程项目（实现 512 字节 bootblock + createimage 工具）是很好的起点，它直接覆盖了实模式汇编、BIOS 中断、ELF 解析和内存布局。ARM 方向则可从 Raspberry Pi 的 bare-metal 教程入手，重点练习异常向量表、DRAM 初始化和串口输出。
